# 🃏 PokerTab

אפליקציית מעקב לערבי פוקר ביתיים: מי חייב למי בסוף הערב, כמה, ומה המאזן הכולל של כל אחד לאורך הזמן.

**חי כאן:** https://flopomaster.github.io/PokerTab/

## מה יש בפנים

- **ערב חדש** — מזינים לכל שחקן כמה כניסות (buy-in) קנה, תוספות חופשיות, וכמה יצא עם. האפליקציה בודקת שהקופה מאוזנת ומציעה איזון מהיר על שחקן אם יש פער.
- **מי מעביר למי** — אלגוריתם שממזער את מספר ההעברות (התאמות מדויקות קודם, ואז greedy על היתרה), עם סימון "שולם" לכל העברה, העתקה בלחיצה ושיתוף ישיר לוואטסאפ.
- **לוח מובילים** — מאזן כולל, ממוצע לערב, ROI, ניצחונות, מקום ממוצע, אחוז ערבים ברווח, הערב הכי טוב והכי גרוע. הטבלה ניתנת למיון לפי כל עמודה.
- **כרטיס שחקן** — כל הסטטיסטיקות של שחקן בודד, גרף רווח/הפסד לפי ערב וטבלת היסטוריה מלאה.
- **סטטיסטיקות** — תארי כבוד שמתעדכנים לבד (המלך, הבנקומט, המכונה, הלוהט, הקפוא, הקומבקיסט, הסלע ועוד), גרף מאזן מצטבר לאורך הזמן, שיאים כלל-קבוצתיים, השוואת ראש-בראש בין שני שחקנים, ורצפי ניצחונות/הפסדים.
- **היסטוריית ערבים** — כל הערבים עם סינון לפי שחקן.

## איפה נשמרים הנתונים

הכל נשמר ב-`localStorage` של הדפדפן — אין שרת ואין חשבון. בהגדרות יש **ייצוא/ייבוא JSON**: מייצאים קובץ, שולחים לחבר, והוא מייבא אצלו כדי לראות את אותם נתונים. יש גם כפתור לטעינת נתוני דמו כדי לראות איך הכל נראה מלא.

## הרצה מקומית

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # בנייה לפרודקשן אל dist/
npm run preview  # תצוגה מקדימה של הבנייה
```

## פריסה

הוורקפלואו ב-`.github/workflows/deploy.yml` בונה ופורס ל-GitHub Pages בכל דחיפה ל-`main` (ולענף הפיתוח).
לפני הפריסה הראשונה צריך להפעיל בהגדרות הריפו: **Settings → Pages → Source: GitHub Actions**.

ה-`base` של Vite מוגדר ל-`/PokerTab/` בבנייה; אם שם הריפו משתנה, יש לעדכן אותו ב-`vite.config.ts`.

## סטאק

React 18 + TypeScript + Vite. בלי ספריות UI או גרפים — הגרפים הם SVG שנכתב ידנית, והעיצוב CSS טהור (עברית RTL, ויב קזינו כהה).
