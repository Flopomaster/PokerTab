# 🃏 PokerTab

אפליקציית מעקב לערבי פוקר ביתיים: מי חייב למי בסוף הערב, כמה, ומה המאזן הכולל של כל אחד לאורך הזמן.

**חי כאן:** https://flopomaster.github.io/PokerTab/

## קלאבים, חשבונות והרשאות

- כל אחד פותח **קלאב** ומקבל **קוד הצטרפות בן 6 תווים**. מי שמזין את הקוד נכנס לרשימת המתנה, ו**אדמין הקלאב מאשר** אותו לפני שהוא רואה משהו.
- אפשר להיות חבר בכמה קלאבים ולעבור ביניהם; לכל קלאב ערבים, שחקנים, לוח מובילים וסטטיסטיקות משלו.
- **הדילר**: מי שפותח ערב הוא האחראי עליו. רק הוא ואדמין הקלאב יכולים לערוך או למחוק את הערב ולסמן העברות כשולמו — לשאר החברים זו תצוגה בלבד.
- **שחקני אורח**: אפשר להוסיף שחקן בלי חשבון (דוד שבא פעם בחודש). אם הוא נרשם מאוחר יותר, האדמין מקשר אותו לחשבון וכל ההיסטוריה עוברת איתו.
- **אדמין הקלאב** מאשר ודוחה בקשות, מסיר חברים, ממנה אדמינים נוספים, מחליף את קוד ההצטרפות ומנהל את שחקני האורח.
- **התחברות** בשם משתמש וסיסמה, נשמרת בין ביקורים ובין מכשירים. מייל הוא שדה לא חובה, ומשמש רק לשחזור סיסמה.

## מה יש בפנים

- **ערב חדש** — מזינים לכל שחקן כמה כניסות (buy-in) קנה, תוספות חופשיות, וכמה יצא עם. האפליקציה בודקת שהקופה מאוזנת ומציעה איזון מהיר על שחקן אם יש פער.
- **מי מעביר למי** — אלגוריתם שממזער את מספר ההעברות (התאמות מדויקות קודם, ואז greedy על היתרה), עם סימון "שולם" לכל העברה, העתקה בלחיצה ושיתוף ישיר לוואטסאפ.
- **לוח מובילים** — מאזן כולל, ממוצע לערב, ROI, ניצחונות, מקום ממוצע, אחוז ערבים ברווח, הערב הכי טוב והכי גרוע. הטבלה ניתנת למיון לפי כל עמודה.
- **כרטיס שחקן** — כל הסטטיסטיקות של שחקן בודד, גרף רווח/הפסד לפי ערב וטבלת היסטוריה מלאה.
- **סטטיסטיקות** — תארי כבוד שמתעדכנים לבד (המלך, הבנקומט, המכונה, הלוהט, הקפוא, הקומבקיסט, הסלע ועוד), גרף מאזן מצטבר לאורך הזמן, שיאים כלל-קבוצתיים, השוואת ראש-בראש בין שני שחקנים, ורצפי ניצחונות/הפסדים.
- **היסטוריית ערבים** — כל הערבים עם סינון לפי שחקן.

## הקמת השרת (Supabase)

הנתונים משותפים בין חברי הקלאב, ולכן צריך בסיס נתונים. ההקמה היא פעם אחת:

1. פותחים פרויקט חדש (חינמי) ב-[supabase.com](https://supabase.com).
2. **SQL Editor → New query** → מדביקים את כל התוכן של [`supabase/schema.sql`](supabase/schema.sql) → **Run**. זה יוצר את הטבלאות, מדיניות ההרשאות (RLS) והפונקציות.
3. **Authentication → Providers → Email**: מכבים את *Confirm email*. ההתחברות היא בשם משתמש, ולרוב המשתמשים אין מייל אמיתי לאשר.
4. **Project Settings → API**: מעתיקים את `Project URL` ואת מפתח ה-`anon public`.
5. בריפו: **Settings → Secrets and variables → Actions → New repository secret**, ומוסיפים שניים:
   `VITE_SUPABASE_URL` ו-`VITE_SUPABASE_ANON_KEY`.
6. הדחיפה הבאה ל-`main` תבנה את האתר עם החיבור.

מפתח ה-`anon` נועד להיחשף בצד הלקוח — מה שמגן על הנתונים הוא ה-RLS שבסכימה, שמוודא שרואים רק קלאבים שאתם חברים מאושרים בהם.

**מצב הדגמה:** בלי המשתנים האלה האפליקציה עולה במצב הדגמה מקומי — אפשר להתנסות בכל הזרימה, אבל החשבונות והקלאבים חיים בדפדפן אחד בלבד ואינם משותפים. מופיע באנר שמסביר את זה.

## נתונים מהגרסה הישנה

מי שהשתמש בגרסה המקומית ימצא בהגדרות כרטיס **"נתונים מהגרסה הישנה"** שמעלה את כל הערבים והשחקנים שנשמרו בדפדפן אל הקלאב הפעיל (שחקנים עם שם זהה מתמזגים). בהגדרות יש גם ייצוא גיבוי של הקלאב ל-JSON.

## אייקון והתקנה כאפליקציה

האפליקציה מוגדרת כ-PWA: הוספה למסך הבית פותחת אותה במסך מלא, בלי סרגל הדפדפן, עם אייקון ומסך פתיחה משלה.
בלשונית **הגדרות** יש כרטיס עם הוראות ההתקנה (ובאנדרואיד גם כפתור התקנה ישיר).

מקור האמת לאייקון הוא קומפוננטת ה-SVG `src/icons/AppIcon.tsx` — ז׳יטון פוקר עם ספייד זהב.
כל קבצי ה-PNG שב-`public/icons` (אייקונים, maskable ומסכי פתיחה ל-iOS) נוצרים ממנה:

```bash
npm run dev                      # בטרמינל אחד
node scripts/render-icons.mjs    # דורש playwright עם chromium
```

## הרצה מקומית

```bash
npm install
cp .env.example .env.local   # לא חובה — בלי זה עולה מצב הדגמה
npm run dev      # http://localhost:5173
npm run build    # בנייה לפרודקשן אל dist/
npm run preview  # תצוגה מקדימה של הבנייה
```

## פריסה

הוורקפלואו ב-`.github/workflows/deploy.yml` בונה ופורס ל-GitHub Pages בכל דחיפה ל-`main` (ולענף הפיתוח).
לפני הפריסה הראשונה צריך להפעיל בהגדרות הריפו: **Settings → Pages → Source: GitHub Actions**.

ה-`base` של Vite מוגדר ל-`/PokerTab/` בבנייה; אם שם הריפו משתנה, יש לעדכן אותו ב-`vite.config.ts`.

## סטאק

React 18 + TypeScript + Vite + Supabase. בלי ספריות UI או גרפים — הגרפים הם SVG שנכתב ידנית, והעיצוב CSS טהור (עברית RTL, ויב קזינו כהה).

שכבת הנתונים מוגדרת כחוזה אחד ב-`src/lib/api.ts`, עם שני מימושים: `supabaseApi.ts` (אמיתי) ו-`demoApi.ts` (מקומי). `apiClient.ts` בוחר ביניהם לפי משתני הסביבה, כך שכל שאר האפליקציה לא יודעת מול מי היא עובדת.
